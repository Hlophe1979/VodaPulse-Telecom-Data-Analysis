# VodaPulse Customer Data Analysis

##  Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** of VodaPulse customer data to understand customer demographics, usage patterns, service experience, and revenue characteristics. The analysis explores factors such as customer age, province, area type, contract type, device type, payment method, network experience, support tickets, load-shedding impact, app engagement, data usage, and ARPU.

##  Objectives

* Understand the characteristics of VodaPulse customers.
* Explore customer usage and engagement patterns.
* Analyse customer service and network experience.
* Investigate ARPU and data usage patterns.
* Identify relationships and trends across different customer segments.
* Generate insights that can support business decision-making.

##  Dataset

The dataset contains customer-level information including:

* Customer demographics
* Geographic information
* Contract and payment details
* Device information
* Network experience
* Support ticket information
* Load-shedding impact
* App engagement
* Data usage
* Average Revenue Per User (ARPU)

### Main Variables

| Variable               | Description                                    |
| ---------------------- | ---------------------------------------------- |
| `Date`                 | Date of the customer record                    |
| `Subscriber_ID`        | Unique customer identifier                     |
| `Customer_Age`         | Customer age                                   |
| `Province`             | Customer province                              |
| `Area_Type`            | Customer area classification                   |
| `Contract_Type`        | Type of customer contract                      |
| `Device_Type`          | Customer device type                           |
| `Payment_Method`       | Customer payment method                        |
| `Network_Experience`   | Customer network experience                    |
| `Support_Ticket_Type`  | Type of support issue                          |
| `Load_Shedding_Impact` | Impact of load shedding                        |
| `App_Engagement`       | Level of app engagement                        |
| `Data_Usage_GB`        | Data usage in gigabytes                        |
| `ARPU_ZAR`             | Average Revenue Per User in South African Rand |

##  Analysis Performed

The project follows these main steps:

1. **Data Understanding** – Inspecting the dataset structure, variables, data types, and summary statistics.
2. **Data Cleaning** – Checking for missing values, duplicates, and data-quality issues.
3. **Univariate Analysis** – Exploring individual numerical and categorical variables.
4. **Bivariate Analysis** – Investigating relationships between customer characteristics, usage, experience, and ARPU.
5. **Geographical Analysis** – Comparing customer patterns across provinces and area types.
6. **Customer Experience Analysis** – Exploring network experience, support tickets, load-shedding impact, and app engagement.
7. **Key Insights** – Summarising the main patterns and findings from the analysis.
